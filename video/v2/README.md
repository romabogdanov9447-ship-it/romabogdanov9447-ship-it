# «Перекупы» v2 — история «Представь…»

Видео: `../output/perekupy_v2_istoriya.mp4` (1080×1920, ~1 мин 54 с, 51 кадр-сцена, озвучка + музыка).

Формат как у референса: история от второго лица, кадр меняется каждые 1–2 секунды, HUD с местом и «временем истории», крупные субтитры по словам.

Дизайн: холодная ночная гамма (#0A1018, #12303F). Жёлтый #FFD21F (цвет смайла) — только у нейросети и бренда: где жёлтое, там работает она. Деньги — зелёный, срочность — оранжевый.
