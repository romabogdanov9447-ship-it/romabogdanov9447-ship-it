Готовое видео: `output/perekupy_novyi_proekt.mp4` (1080×1920, 30 fps, ~85 с, озвучка + музыка).

## Пересборка

Текст и акцентные (оранжевые) слова субтитров — в `script.json`.

```bash
pip install edge-tts pillow numpy           # + ffmpeg
python3 tts.py script.json build/vo         # озвучка (голос ru-RU-DmitryNeural) + тайминги слов
python3 render.py build                     # графика по сценам (ONLY=hook,cta — перерисовать отдельные)
python3 assemble.py build output/perekupy_novyi_proekt.mp4
```

Свой голос: замените `build/vo/<сцена>.mp3` своей записью и подправьте тайминги в `build/vo/timing.json`
(или оставьте TTS-тайминги, если темп похожий).
