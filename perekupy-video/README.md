# «Перекупы» — рекламный 3D-ролик

Готовый ролик: `out/perekupy_ad_1080x1920_light.mp4` (1080×1920, 60 с, озвучка ElevenLabs).

Исходники сцен: `film/` (Three.js, рендер по кадрам в headless Chromium через `render.js`),
звук: `audio/mix2.py` (музыка и SFX синтезируются, голос — пользовательская запись).
Для запуска нужны `npm i three@0.170.0`, Playwright и шрифты Inter (*.otf) в корне проекта.
